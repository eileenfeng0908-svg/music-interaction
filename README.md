# Five Rooms

An interactive, audio-reactive artwork. Five unnamed music styles, three pieces each; every piece has its own generative visual that moves with the sound.

Open `index.html` in a browser, or deploy the folder as a static site (no build step).

- `index.html` — the page: sound, visuals and controls
- `audio/track-*.js` — the artist's tracks, stored as text so the page can analyse them even when opened as a local file
